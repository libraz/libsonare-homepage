# パンとステレオ幅

**パン**はトラックの左右の位置を決めます。

**ステレオ幅**は、そのイメージがどれだけ広がるかを決めます。

この 2 つでミックスの横方向の空間を作り、すべてを中央に積み重ねる代わりに各パートへ居場所を与えます。このページでは、これらのコントロールを libsonare の `PannerProcessor` と `StereoWidthProcessor` に沿って説明します。基礎は [ミキシングの基礎](../concepts/mixing-basics.md) を参照してください。

## パン位置

**パン**は、トラックを左端から右端まで動かします。フィールドに広げると各パートに余裕ができ、マスキング（似た帯域のパートが互いを覆い隠すこと）も減ります。ただし「パン」という 1 語には、位置を*どうチャンネルへ対応づけるか*と*中央をどれだけの音量にするか*という別々の判断が 2 つ隠れていて、libsonare はその両方を公開しています。

たとえばボーカルを中央、ギターを左、キーボードを右に置くと、各パートに別々の居場所ができ、3 つを中央に重ねたときより一つひとつを追いやすくなります。混み合ったミックスほど、この左右の配置がパートの分離を決めます。

## パンモード: 位置をどうチャンネルへ対応づけるか

**パンモード**はこの対応づけを選びます。

- **本来のパン**はモノラルソースをフィールド上で動かします。
- **バランス**は、ステレオトラックを再配置するのではなく片側を下げます。
- **左右独立**は各側を別々に配置します。

モードの違いが最も大きく出るのはステレオソースです。libsonare の本来のパン（`stereoPan`）は、まずトラックを `(L + R) / 2` でモノラルに畳み、そのモノラル信号を配置します。そのためステレオイメージは必ず潰れ、左右で異なる成分は失われ、逆相の成分は打ち消されます。既定のバランスならイメージは保たれます。

## パンロー: パンしても音量を一定に保つ

ソースを中央から片側へ振ると、補正しない限り知覚上の音量が跳ねることがあります。**パンロー**は、中央をサイドに対してどれだけ減衰させるかを決め、動かしただけでパートが大きくなったり小さくなったりしないようにします。libsonare には次の 4 つがあります。

| パンロー | 中央でのチャンネルごとのゲイン | 一定に保つもの |
|----------|-------------------------------|----------------|
| `const3dB`（既定） | −3 dB（0.707） | 総パワー。スピーカー再生で効くのはこちら |
| `const4.5dB` | −4.5 dB（0.595） | 2 つの中間 |
| `const6dB` | −6 dB（0.5） | モノラル合算（定振幅） |
| `linear0dB` | 0 dB（1.0） | なし。中央を補正しない |

中央の減衰が出力に現れるのは本来のパンのときだけです。既定のバランスモードでは、パンを向けた側のチャンネルは等倍のまま、反対側だけが下がります。そのため中央のトラックはどのパンローでも 0 dB で、パンローが決めるのは反対側がどれだけ速く下がるかだけです。計算の詳細は [ミキシングエンジン](../../mixing.md#パンモードとパンロー) を参照してください。

## ステレオ幅

**ステレオ幅**はイメージを狭めたり広げたりします。通常は、ミッド成分（左右に共通する成分）に対するサイド成分（左−右、つまり左右で異なる成分）の量を調整します。

広げると空間の広がりが増しますが、[モノラル互換性](../concepts/mono-compatibility.md)の問題を招くことがあります。サイドだけの成分はモノラル合算で消えます。純粋な M/S 幅調整はモノラルの合算を保ったままサイドを拡大・縮小しますが、Haas ディレイ、極性の変更、その後のリミッティング、比較時の正規化によってモノラルの結果は変わります。

狭めるとフォーカスが締まり、モノラルでの頑健さが増します。幅はストリップの後半、パンの後に置かれ、配置済みの信号に作用します。そのため、パンしたモノラルソースでは幅を変えると位置も動きます。左いっぱいのモノラルソースは幅 0 で中央の −6 dB になり、幅 2 では反対側のチャンネルに半分のレベルの逆相成分が現れます。モノラルソースは幅を 1 のままにし、パンで配置してください。

::: details libsonare がパンと幅をどうモデル化するか
パンは `PanMode`（本来のパン／バランス／独立）と `PanLaw`（中央の減衰）で構成される `PannerProcessor` で、ストリップではフェーダーの後に置かれます。ステレオ幅は `StereoWidthProcessor` で、ミッド／サイド表現に作用し、配置済みの信号に効くよう信号順の後半にあります。両者ともクリックのない変化のためパラメータスムージングされ、ポストフェーダーの `GoniometerBuffer` へ書き込まれるので、結果のイメージを計測できます。配置は [チャンネルストリップ](./channel-strip.md) の固定信号順に一致します。
:::
