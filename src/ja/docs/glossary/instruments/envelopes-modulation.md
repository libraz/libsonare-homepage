# エンベロープとモジュレーション

生のオシレーターは静的です。キーを押せば、1 つの音量と 1 つの音色で延々と鳴り続けます。実際の楽器はそうではなく、ノートは膨らみ、明るくなり、減衰し、消えていきます。**モジュレーション**は「何かが時間とともに変化すること」を表す総称で、平板なシンセ音を音楽的な音に変えるのはこれです。

このページでは、最もよく出会う 2 種類のモジュレーション源（エンベロープと LFO）、モジュレーションとして働く演奏入力（ベロシティとキートラッキング）、そして源と行き先を配線する**モッドマトリクス**を説明します。概念だけで、コードは出てきません。変調される側のブロックは、先に [シンセシスの基礎](./synthesis-basics.md) で押さえてください。

## ADSR アンプエンベロープ

**エンベロープ**は、ノートごとに 1 回だけ展開するカーブです。古典的なエンベロープは **A**ttack（アタック）、**D**ecay（ディケイ）、**S**ustain（サステイン）、**R**elease（リリース）の 4 段階、略して ADSR で構成されます。最も重要なエンベロープは、ノートの始まりから終わりまでの音量を制御するものです。

| 段階 | 制御するもの | 長い値の聞こえ方 | 短い値の聞こえ方 |
|------|--------------|------------------|------------------|
| **アタック** | 無音から最大まで立ち上がる時間 | ゆっくり膨らむ（パッド、ストリングス） | 瞬時の打音（撥弦、ピアノ） |
| **ディケイ** | ピークからサステインの高さまで下がる時間 | じわじわ落ち着く | 素早く下がる |
| **サステイン** | キーを押している間に保持される*高さ*（時間ではない） | 大きく保たれる本体（高い値） | 押していても小さい/消える（低い・ゼロの値） |
| **リリース** | キーを離した後に消えるまでの時間 | 長い余韻、残響のよう | 唐突に途切れる |

撥弦的な音は、速いアタック・速いディケイ・サステインゼロ・短いリリースです。パッドは、遅いアタック・高いサステイン・長いリリースです。同じオシレーターでも、エンベロープだけでまったく別の楽器になります。

<SonareDemo id="synth-adsr" />

::: info アタック・ディケイ・リリースは時間、サステインは高さ
ADSR の 4 つのうち 3 つは時間（ミリ秒）です。サステインだけが例外で、キーを押し続けている間ずっと保持される*音量の高さ*を表します。だから「サステインゼロ」のパッチは、キーを押したままでも無音になります。
:::

## 独立したフィルターエンベロープ

アンプエンベロープは*音量*を整形します。もう 1 つの独立したエンベロープで**フィルターカットオフ**を整形すると、*音色*が独自の時間経過で変化します。速いフィルターアタックがすぐに下がれば、シンセベースの明るい「プラック」になります。遅いフィルターアタックなら、パッドがゆっくり開いていきます。2 つのエンベロープは独立しているので、小さくなりながら明るくなるノートのような、どんな組み合わせも作れます。

## LFO — ゆっくり繰り返す動き

**LFO**（低周波オシレーター）は、ピッチとして聞こえないほど遅いオシレーターで、典型的には 1 Hz 未満から数 Hz 程度で振れます。直接鳴らすのではなく、そのゆるやかな上下の波で何かを*変調*します。

- LFO → **ピッチ** = **ビブラート**（保持したノートの小さな揺れ）。
- LFO → **音量** = **トレモロ**（脈打つ音量）。
- LFO → **フィルターカットオフ** = ベースやエレクトロニックな質感のゆっくりした「ワブル」。

LFO の主要なつまみは **レート**（周期の速さ）と **デプス**（行き先をどれだけ動かすか）の 2 つです。

## ベロシティとキートラッキング

モジュレーション源のうち 2 つは、シンセ本体ではなく*演奏*から来ます。

- **ベロシティ** — キーを叩く強さで、0〜127 の数値で送られます（[MIDI の基礎](./midi-basics.md) を参照）。音量へ配線すれば弱く弾いた音は小さく、強く弾いた音は大きくなります。フィルターへ配線すれば強く弾くほど明るくなり、実際の楽器を強く弾いたときの振る舞いに近づきます。
- **キートラッキング** — どの鍵を弾いたか。弾いたピッチをフィルターカットオフへ配線すると、高音も低音と同じ明るさに保てます（これがないと、高音は倍音が固定カットオフより上に出てしまい、こもって聞こえがちです）。

## モッドマトリクス

**モッドマトリクス**は、ここまでの源と、それが動かす対象をつなぐパッチベイ、つまり「何が何を動かすか」の配線表です。ルーティング 1 本は 3 つの要素で決まります。

| 要素 | 意味 | 例 |
|------|------|----|
| **ソース**（源） | 動かす側 | LFO 1、LFO 2、アンプエンベロープ、フィルターエンベロープ、ベロシティ、キートラッキング、モッドホイール、ランダム |
| **デスティネーション**（行き先） | 動かされる側 | ピッチ（セント。100 セントで半音）、フィルターカットオフ（セント）、音量（ゲイン）、パン（位置） |
| **デプス**（深さ） | どれだけ、どちら向きに | 大きな正のデプス = 強く上向きに動かす、負 = その逆 |

「LFO 1 → ピッチ、小さなデプス」はビブラート、「ベロシティ → カットオフ、大きなデプス」は弾き方で変わる明るさ、「フィルターエンベロープ → カットオフ」は定番のシンセプラックです。ひと握りの源と行き先を組み替えるだけで、表現の幅は大きく広がります。

::: details libsonare での実装
NativeSynth では、モジュレーションは `SynthPatch` の中にあります。アンプエンベロープは `ampAttackMs`・`ampDecayMs`・`ampSustain`・`ampReleaseMs`、独立したフィルターエンベロープは対応する `filterAttackMs` / `filterDecayMs` / `filterSustain` / `filterReleaseMs` の組です。2 つの LFO は `lfoRateHz` と `lfo2RateHz` で設定します（`lfoToPitchCents` は直接ビブラートを掛けるショートカットです）。自由なルーティングは `modRoutings` にあり、`{ source, destination, depth }` の配列で、`source` は `'lfo1'`・`'lfo2'`・`'amp-env'`・`'filter-env'`・`'velocity'`・`'key-track'`・`'mod-wheel'`・`'random'` のいずれか、`destination` は `'pitch-cents'`・`'cutoff-cents'`・`'amp-gain'`・`'pan-units'` のいずれかです。空でない `modRoutings` はベースプリセットのマトリクスを置き換え、マトリクスは最大 8 ルーティングを保持します。
:::
