# 実践ユースケース

音声の納品物を作る作業と、アプリを開発する作業を通して解説します。制作向けの手順には CLI スクリプトを掲載し、ブラウザミキサーのガイドでは動作するデモと、ミキシング画面の実装に必要な API を紹介します。

掲載しているコマンドはすべて現行エンジンに対して実行し、示している数値はそのとき出力されたものです。

## 前提

ブラウザミキサーのガイドは WASM/JavaScript API を使います。制作向けの手順は Python CLI（`pip install libsonare`）を使います。CLI の手順に関わる次の 2 点は、[CLI リファレンス](./cli.md)で解説しています。

- 2 つの CLI でコマンドは揃っていません。シーンミキサー（`mix`）、プリセット駆動の `master` と `mastering-chain`、`declip` は Python CLI 専用です。逆に低レベルなメータリング系（`meter`、`clipping`、`phase`、`stereo`、`dynamic-range`）はネイティブ CLI 専用です。[どちらの CLI を使うか](./cli.md#どの-cli-を使っているか) を参照してください。
- ほとんどのコマンドはモノラル前提です。ミキシングとマスタリングはステレオペアを最後まで保ちますが、計測系のコマンドの多くはモノラルにダウンミックスし、その旨を標準エラー出力に出します。各ページでラウドネスを別途 `lufs` で測らずマスタリングレポートから読んでいるのはこのためです。[ステレオとモノラルの扱い](./cli.md#ステレオとモノラルの扱い) を参照してください。

すべてのコマンドが `--json` を受け付け、失敗はすべて[終了コード](./cli.md#終了コード)に対応づけられています。これらの手順が「打てる」だけでなく「スクリプトに組める」のはそのためです。

::: tip スクリプトではなく API を使う場面
UI やプラグイン、リアルタイム処理に行き着くユースケースは、シェルスクリプトではなく API の領分です。[JavaScript API](./js-api.md)、[Python API](./python-api.md)、[C++ API](./cpp-api.md) から始めてください。考え方は同じで、このセクションの各ページからも要所で対応するガイドへリンクしています。
:::
