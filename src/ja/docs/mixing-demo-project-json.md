# ミキシングデモのプロジェクト JSON

[ミキシングスタジオ](/ja/mixing)は、トラックの配置とミキシングの操作値をプロジェクト設定ファイルに保存します。デコード済み音源は含みません。**プロジェクト設定を書き出し**で `libsonare-mix-project.json` を保存し、対応する音声ファイルを開いてから **プロジェクト設定を読み込み**で操作値を復元します。アプリの構成と参考にするソースは、[ブラウザでミキシングアプリを作る](./use-cases/browser-mixer.md)を参照してください。

::: warning これはミキサーシーンの形式ではありません
これは [ミキシングシーン JSON](./mixing-scene-json.md) リファレンスとは別の交換形式です。*シーン*はストリップ・バス・VCA グループ・接続からなるミキサーグラフ全体を記述し、`Mixer.toSceneJson()` / `fromSceneJson()` で往復します。以下のデモプロジェクトファイルはブラウザデモだけが読むトラックごとのフラットなアレンジで、エンジンの `fromSceneJson(...)` は受け付けません。ミキサーを動かすなら、こちらではなくシーン形式を使ってください。
:::

下のデモは `/ja/mixing` ページではなくエンジン自身のレーンミキサーですが、鳴らしているのはこのファイルが記述しているものそのものです。フェーダーとミュートを持つトラックが 3 本あり、各バンドが `tracks[]` の 1 要素にあたります。フェーダーはその要素の `faderDb`、ミュートは `muted` で、デモはこの 2 つをシーン形式のストリップ（`strips[].faderDb`）と `setSoloMute` でエンジンに渡しています。デモに対応物がないのは `offsetSeconds` です。デモのクリップはすべて 0 秒から始まります。エンジンがすでに扱えるストリップ設定に対して、このファイルが追加しているのは、トラックをタイムライン上で後ろにずらす情報です。

## 形

以下の例は省略版で、代表的なキーの一部だけを示しています。実際の書き出しには、トップレベルの追加フィールド（`reverb` や `vcaGains` など）やトラックごとの追加設定も含まれます。

```json
{
  "version": 1,
  "masterFaderDb": 0,
  "tracks": [
    {
      "id": "track-id",
      "name": "Lead Vocal",
      "offsetSeconds": 1.5,
      "inputTrimDb": 0,
      "faderDb": -3,
      "pan": 0,
      "width": 1,
      "muted": false,
      "soloed": false,
      "polarityLeft": false,
      "polarityRight": false
    }
  ]
}
```

一部の設定だけを含むファイルも読み込めます。`masterFaderDb`、`reverb`、`vcaGains`、`tracks` のうち、少なくとも 1 つを含めてください。`version` を含める場合は `1` にします。`tracks` は `id` または `name` を持つトラック設定の配列、`reverb` と `vcaGains` はオブジェクトである必要があります。`strips`、`buses`、`connections` を持つエンジンのシーンは、操作値を変更する前に拒否します。`version` を省略した設定ファイルも読み込めます。

指定した操作値は各フィールドの型に合わせてください。数値は有限の数である必要があり、`"-6"` のような文字列は拒否します。操作値やオートメーションの要素が不正な場合は、設定を適用する前にファイル全体を拒否します。

省略したトップレベルの設定は現在の値を保持します。指定したトラックやリバーブ設定の中で欠けている操作値は、既定値で埋められます。範囲外の値はクランプされます（`faderDb` は -60〜+12 dB、`masterFaderDb` と `vcaGains` の各値は -24〜+12 dB、`offsetSeconds` はクリップがタイムラインに収まる範囲）。

`offsetSeconds` はアレンジタイムライン上のクリップ開始時刻です。デモは WASM ミキサーを呼ぶ前に各ステムをその分だけパディングするため、画面上の開始時刻がオフラインバウンスにも保たれます。ファイルは音声を含まないので、再インポート時は音声を再読み込みしたあとに `id`（または `name`）でトラックを照合します。どのトラックにも一致しなかった設定は捨てられ、1 つも適用できなかった場合はデモがその旨を表示します。
